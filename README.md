# dwg-editor — плагин Claude Code для чертежей DWG/DXF

Открывает, показывает и редактирует чертежи AutoCAD прямо из Claude Code.

## Как это работает

DWG — закрытый формат. Плагин конвертирует `DWG → DXF` через **ODA File Converter**, редактирует DXF библиотекой **ezdxf** и при сохранении конвертирует обратно `DXF → DWG`. Файлы `.dxf` открываются напрямую, без конвертера.

## Требования

1. **Python 3.10+** (на Windows: `winget install Python.Python.3.12`). Заглушка `python.exe` из Microsoft Store не подходит.
2. **ODA File Converter** (бесплатно, нужна регистрация): https://www.opendesign.com/guestfiles/oda_file_converter. Нужен только для `.dwg`.
   Если установлен не в стандартную папку, задайте переменную среды `ODA_FILE_CONVERTER` с путём к `ODAFileConverter.exe`.

Зависимости Python (`mcp`, `ezdxf`, `matplotlib`) устанавливаются автоматически в отдельное окружение при первом запуске. Установка идёт в фоне и занимает пару минут: пока она не закончилась, сервер отвечает единственным инструментом `status`. Когда он сообщит, что зависимости установлены, перезапустите сервер (`/mcp` → reconnect) или приложение.

## Установка

Из GitHub (маркетплейс `dwg-tools` лежит в самом репозитории):

```bash
claude plugin marketplace add admproekt/dwg-editor
claude plugin install dwg-editor@dwg-tools
```

В десктопном приложении Claude Code: **+ → Plugins → Add plugin**, плагин `dwg-editor` из маркетплейса `dwg-tools`.
Если маркетплейса в списке нет, добавьте его в `~/.claude/settings.json`:

```json
{
  "extraKnownMarketplaces": {
    "dwg-tools": { "source": { "source": "github", "repo": "admproekt/dwg-editor" } }
  },
  "enabledPlugins": { "dwg-editor@dwg-tools": true }
}
```

Для разработки, из папки проекта:

```bash
claude --plugin-dir .
```

После установки Python или ODA File Converter перезапустите приложение, чтобы оно увидело обновлённый PATH.

## Использование

- `/dwg путь\к\чертежу.dwg` — открыть и показать содержимое.
- Или просто просите: «открой plan.dwg, перенеси слой "Мебель" в красный цвет», «замени в штампе "Иванов" на "Петров" и сохрани как plan_v2.dwg».

## Навыки

Навык — это инструкция для Claude о том, как работать с чертежами определённого типа. Он подключается сам, когда запрос совпадает с его описанием (`description`), либо вызывается по имени: `/dwg-editor:<имя навыка>`.

| Навык | Для чего | Когда срабатывает |
| --- | --- | --- |
| `dwg-editing` | Общий порядок работы: открыть, изучить, править, проверить, сохранить; правила безопасности | Любая работа с `.dwg` и `.dxf` |
| `longitudinal-profile` | Продольные профили трасс: таблица сечения, объединение коротких участков, наложение подписей | «Продольный профиль», «таблица сечения», «подписи налезают» |

### Свои навыки

Навык для нового типа чертежей проще всего создать командой `/dwg-editor:new-skill <тип чертежа>`: Claude задаст вопросы, изучит ваш чертёж-образец и напишет `SKILL.md`.

Вручную навык — это папка с файлом `SKILL.md`. Первым идёт блок с `name` и `description`, дальше текст инструкции:

```markdown
---
name: floor-plan
description: Use for AutoCAD floor plans (планы этажей): walls, doors, room labels. Также для «план этажа», «экспликация помещений».
---

# План этажа

Общие правила и список инструментов смотрите в навыке `dwg-editing`.
...
```

Где хранить:

| Место | Путь | Кто видит |
| --- | --- | --- |
| Личный | `~/.claude/skills/<имя>/SKILL.md` (Windows: `%USERPROFILE%\.claude\skills\<имя>\SKILL.md`) | только вы, во всех проектах |
| Проектный | `.claude/skills/<имя>/SKILL.md` в папке проекта | все, у кого есть проект |
| Плагин | `skills/<имя>/SKILL.md` в этом репозитории | все, кто установил плагин |

Советы:

- Одна задача или один тип чертежа на навык. Общие правила остаются в `dwg-editing`.
- Пишите `description` словами, которыми вы называете этот тип чертежа: по ним навык находят. Если навык не подключается, поправьте описание.
- Длинные справочники и примеры кладите рядом с `SKILL.md` отдельными файлами, в самом навыке оставьте только то, что нужно всегда.
- Всё, что выведено из одного образца чертежа, помечайте как «по образцу» и просите сверять на новом чертеже.
- После изменения навыков в плагине поднимите версию в `.claude-plugin/plugin.json`, иначе установленная копия не обновится.

## Инструменты MCP

| Группа | Инструменты |
| --- | --- |
| Файлы | `open_drawing`, `new_drawing`, `save_drawing`, `close_drawing` |
| Просмотр | `drawing_info`, `list_layers`, `list_entities`, `get_entity`, `render_preview` |
| Создание | `add_layer`, `add_line`, `add_circle`, `add_arc`, `add_polyline`, `add_text`, `add_mtext`, `add_linear_dimension` |
| Правка | `modify_entity`, `move_entities`, `delete_entities`, `replace_text` |
| Преобразования | `copy_entities`, `rotate_entities`, `scale_entities`, `mirror_entities` |
| Слои | `set_layer_properties` (цвет, тип и вес линии, вкл/выкл, заморозка, блокировка, переименование), `delete_layer` |
| Растяжение | `stretch_entities` (как STRETCH в AutoCAD), `close_gap` (вырезать полосу и сомкнуть края, например сузить плиту) |
| Пакетные | `modify_entities`, `move_entities_each` (много объектов за один вызов, при ошибке чертёж не меняется) |
| Движки | `engine_status` (что доступно на ПК; пока работает только ezdxf) |

Тесты инструментов на синтетических чертежах (без AutoCAD и ODA): из корня репозитория `python -m unittest discover -s tests -v` интерпретатором из окружения плагина.

## Ограничения

- Работает с пространством модели. Листы (layouts) и видовые экраны не редактируются.
- При круговой конвертации DWG→DXF→DWG динамические блоки и прокси-объекты сторонних приложений могут потерять часть свойств. Перед перезаписью DWG создаётся копия `.bak`.
