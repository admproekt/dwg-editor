# Продольный профиль трассы (DWG/DXF)

Дополняет навык `dwg-editing`: порядок работы, правила безопасности и список инструментов берите оттуда. Здесь только то, что относится к профилям. Всё ниже выведено из одного образца (`1-2.dwg`), поэтому на новом чертеже сначала сверьтесь с реальными данными (`drawing_info`, `list_layers`, `list_entities`, превью).

## Как обычно устроен чертёж

- Модель в миллиметрах. Масштаб по горизонтали проверьте: ширина ячейки в мм, делённая на 10, должна равняться подписи «Расстояние, м» (то есть 1 м = 10 мм при 1:100).
- Слои из образца: `Таблица сечения` (рамка, линии ячеек, подписи таблицы), `Оформление профиля` (подписи глубин вдоль красной линии), `Подписи масштабов`, `Пересечения с трассами` (синий значок и подписи пересечения).
- Таблица состоит из полос по высоте: строка отметок «Z-отметка, м» и строка «Расстояние, м». Белая таблица относится к основной линии профиля, красная (цвет 1 по ACI) ко второй. Границы полос найдите по горизонтальным линиям.
- Ячейки разделены вертикальными двухточечными полилиниями. Подпись расстояния стоит по центру ячейки. В узких ячейках подпись повёрнута на 90°.
- Подписи отметок повёрнуты на 90° и стоят у границ ячеек. Их порядок слева направо совпадает с порядком границ, но автор мог сдвинуть подпись на 1–3 мм от линии. Сопоставляйте подписи с границами по порядку, а не по координате.
- У TEXT с выравниванием не по левому краю положение задаёт `align_point`, а не `insert`. `move_entities` сдвигает оба.
- Ширина текста высотой 2,5 мм в шрифте образца около 1,2 мм на символ. Это оценка, на другом шрифте измерьте.

## Объединение коротких участков

Порог по умолчанию 0,2 м. Спросите у пользователя, если он не назвал значение.

1. Идите по ячейкам слева направо. Участок короче порога сливается с ячейкой слева, его значение прибавляется к её значению.
2. Первая ячейка без левого соседа остаётся основой и принимает следующие короткие участки.
3. Удалите вертикальную линию между участками и подпись короткого участка. Подпись основы замените суммой, формат `5,15`, и поставьте по центру новой ячейки.
4. Проверьте: ширина каждой ячейки / 10 равна её подписи, сумма всех участков не изменилась.
5. Если у таблицы есть строка отметок, подписи на удалённых границах теперь висят без линии. Не удаляйте их сами: спросите пользователя.

## Наложение подписей

Находите по габаритам текста, а не по координатам вставки. Порядок действий:

1. Сначала объедините короткие участки, часть наложений уйдёт сама.
2. Остальные разведите по высоте ступенями, если в полосе или над линией профиля есть место. Подписи, лежащие в одной точке по X, так не разойдутся.
3. Если места нет, разнесите подписи по горизонтали с шагом около 2,8 мм при высоте текста 2,5. Каждой сдвинутой подписи нужна выноска к исходной точке: тонкая полилиния (`lineweight` 9) на слое подписи и того же цвета.
4. Уменьшение высоты текста не помогает для подписей в одной точке. Предлагайте его только для подписей, которые просто стоят слишком близко.

## Как сообщать о результате

- Сохраняйте в новый файл с суффиксом версии (`_v2`, `_v3`), оригинал не трогайте.
- Покажите список изменений: что объединено, какие подписи удалены, сколько сдвинуто.
- Приложите превью до и после. Встроенное превью рисует все линии одной толщины, поэтому выноски в нём выглядят жирными. Для точной проверки отрисуйте нужный фрагмент отдельно.
- Массовые правки (десятки подписей) подтверждайте у пользователя до применения, как требует `dwg-editing`.
