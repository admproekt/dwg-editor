# 3d-editor: 3D-модели и BIM

Плагин Claude Code для работы с 3D-моделями и BIM. Объединяет несколько движков, потому что нужный зависит от объекта и задачи.

**Статус:** работает чтение и просмотр IFC (файловый уровень, IfcOpenShell). Остальные движки и создание модели по 2D-чертежам пока в плане.

| Движок | Для чего | Статус |
| --- | --- | --- |
| Файловый уровень (IfcOpenShell) | IFC без САПР: чтение, просмотр | Есть |
| Fusion | 3D-модели изделий: детали, сборки, обработка, симуляция | В плане |
| Revit | BIM здания и инженерных систем | В плане |
| Forma | Ранние проработки площадки и здания | В плане |
| Navisworks | Координация, коллизии, сводные модели | В плане |

План, этапы и открытые вопросы: [../../docs/PLAN-engines-and-viewer.md](../../docs/PLAN-engines-and-viewer.md), раздел 8.

## Инструменты MCP

| Инструмент | Что делает |
| --- | --- |
| `ifc_open`, `ifc_close` | Открыть IFC и вернуть сводку (схема, проект, этажи, элементы по классам) / закрыть |
| `ifc_list_elements` | Список элементов с фильтрами по классу, этажу и имени |
| `ifc_get_element` | Атрибуты и наборы свойств элемента по GlobalId |
| `ifc_viewer_open` | Запустить локальный просмотрщик и вернуть адрес для встроенного браузера |
| `viewer_get_selection` | Что выделено в просмотрщике |
| `viewer_get_messages` | Замечания пользователя из просмотрщика |
| `viewer_highlight` | Подсветить элементы в просмотрщике |

Просмотрщик: локальный сервер внутри MCP-процесса, слушает только `127.0.0.1`, требует случайный токен в адресе, IFC не меняет. Модель рисуется Three.js, который браузер загружает с `cdn.jsdelivr.net` (нужен интернет).

## Требования

Python 3.10+. Зависимости (`mcp`, `ifcopenshell`, `numpy`) ставятся автоматически в отдельное окружение при первом запуске. Установка идёт в фоне и занимает несколько минут: пока она не закончилась, сервер отвечает единственным инструментом `status`. Когда он сообщит, что зависимости установлены, перезапустите сервер или приложение.

## Навыки

| Навык | Для чего |
| --- | --- |
| `3d-engine-selection` | Выбор движка по объекту и задаче |
| `ifc-viewing` | Открыть IFC, разобраться в нём, показать в браузере |

## Тесты

Из папки плагина интерпретатором из его окружения:

```bash
python -m unittest discover -s tests -v
```

Тесты строят синтетическую модель (плита и четыре стены) и проверяют чтение, фильтры, свойства, геометрию и сервер просмотрщика (токен, выделение, замечания, подсветка).

## Проверка из папки репозитория

```bash
claude --plugin-dir plugins/3d-editor
```

Для чертежей DWG и DXF используйте соседний плагин `dwg-editor` (в корне репозитория).
