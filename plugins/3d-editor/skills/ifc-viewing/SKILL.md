# Чтение и просмотр IFC

Инструменты сервера `3d-editor` (файловый уровень, через IfcOpenShell). Это чтение и просмотр: IFC эти инструменты не меняют.

## Порядок работы

1. **Открыть:** `ifc_open(path)`. Вернёт схему, проект, этажи и число элементов по классам. Если пользователь не назвал файл, спросите путь.
2. **Разобраться:** `ifc_list_elements` с фильтрами (`ifc_class`, `storey`, `name_contains`), `ifc_get_element(global_id)` для атрибутов и наборов свойств.
3. **Показать:** `ifc_viewer_open()` возвращает адрес локального просмотрщика. Откройте его во встроенном браузере Claude Desktop (инструмент `preview_start` с параметром `url`). Адрес содержит токен, не показывайте его вне этого разговора.
4. **Связь с просмотрщиком:**
   - `viewer_get_selection()`: что пользователь выделил щелчком (Shift добавляет в выделение);
   - `viewer_get_messages()`: замечания, которые он написал в панели справа, вместе с выделением на момент отправки;
   - `viewer_highlight(global_ids, label)`: подсветить найденные элементы.
   Просмотрщик не присылает сообщения сам: пользователь пишет в чат «смотри выделенное» или «прочитай замечание», и вы вызываете инструмент.

## Правила и ограничения

- Единицы в IFC обычно метры. Не угадывайте масштаб, смотрите на данные.
- Просмотр строится из геометрии IfcOpenShell. Элементы без геометрии (чистые пространственные, типы) не показываются, это нормально.
- Для больших моделей (десятки тысяч элементов) открытие просмотрщика может занять время и память. Предупредите пользователя.
- Просмотрщик загружает Three.js с `cdn.jsdelivr.net`: нужен доступ в интернет. Без сети модель не покажется.
- Создание и правка BIM-моделей, а также чертежи DWG и DXF вне этого навыка. Для DWG используйте плагин `dwg-editor`.
