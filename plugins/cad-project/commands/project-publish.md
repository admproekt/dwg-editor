---
description: Подключить проект к серверу git и отправить его (ветка, теги, файлы LFS)
argument-hint: <адрес репозитория, например http://сервер:3000/проект/имя.git>
---

Отправьте активный проект на сервер: `$ARGUMENTS`.

1. Если адрес не назван, спросите его и напомните: репозиторий на сервере должен быть пустым, создан без README. Как поднять сервер, написано в `docs/git-server.md` плагина cad-project.
2. Вызовите `project_status`. Если есть незакоммиченное, скажите, что на сервер уйдёт только закоммиченное, и спросите, закоммитить ли сначала.
3. Скажите, что первая отправка больших файлов (чертежи, модели) может занять много времени, и вызовите `project_publish`. Это отправка данных проекта на сервер, делайте её только после согласия инженера.
4. Если инструмент вернул ошибку входа, не пытайтесь вводить пароль сами: попросите инженера выполнить в терминале `git ls-remote <адрес>` и войти (логин и токен запомнятся), затем повторите.
5. Покажите итог: адрес, ветка, отправлено ли. Подскажите коллегам команду `/project-clone <адрес> <папка>`.
