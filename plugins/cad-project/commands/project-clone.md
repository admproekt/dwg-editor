---
description: Скопировать проект с сервера git в новую папку и открыть его
argument-hint: <адрес репозитория> <папка, например C:\Projects\Сириус>
---

Скопируйте проект: `$ARGUMENTS`.

1. Если адрес или папка не названы, спросите. Рекомендуйте `C:\Projects\<имя>`: новая или пустая папка вне других репозиториев.
2. Вызовите `project_clone`. Копирование с файлами LFS может занять много времени.
3. Если вход на сервер не удался, не вводите пароль сами: попросите инженера выполнить в терминале `git ls-remote <адрес>` и войти, затем повторите.
4. Покажите итог: папка, число проверенных исходников и проблемы (`sources.problems`), стадии и следующая стадия, замечания (`notes`).
5. Напомните: чтобы агент подхватил `CLAUDE.md` и навыки проекта, открывайте приложение в папке проекта.
